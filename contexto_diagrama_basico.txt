📜 Documentação de Regras de Negócio (RN)
Este documento descreve o funcionamento lógico e as restrições do sistema de gerenciamento de Board Games.

1. Navegação e Interface Global
RN01 - Menu Fixo: O menu principal contendo as opções <JOGO>, <MECANICAS>, <COMPONENTES> e <TEMAS> deve ser persistente (fixo) em todas as páginas da aplicação.

RN02 - Ações de Gerenciamento: Cada sessão (Mecânicas, Temas, Componentes) deve obrigatoriamente prover as funções:

Novo: Criar novo registro.

Lista: Visualizar todos os itens.

Editar: Alterar dados existentes.

Renomear: Alteração rápida de rótulo.

2. Gerenciamento de Jogos
RN03 - Busca e Filtros: A listagem de jogos deve permitir a filtragem por:

Nome do jogo ou ID (busca textual).

Mecânica associada.

Tema associado.

RN04 - Upload de Capa: O sistema deve permitir o upload de uma imagem para a capa. Formatos suportados: JPG/PNG.

3. Lógica de Cálculo de Peso (Complexidade)O Peso do jogo é um valor calculado dinamicamente com base nos componentes e regras adicionadas. O valor base inicia em 0.1 e cresce conforme os critérios abaixo:Fórmula de CálculoO cálculo segue a soma de variáveis $P$ (Peso), onde cada categoria possui um incremento e um teto:$$Peso = P_{tempo} + P_{mecanica} + P_{componentes} + P_{vitoria} + P_{derrota} + P_{estrutura} + P_{especial}$$

4. Restrições do Formulário de Jogo
Listas Pré-definidas
Jogadores: Seleção de um intervalo entre 0 e 50.

Tempo Médio (minutos): 5, 10, 15, 20, 25, 30, 35, 40, 45, 50, 60, 80, 100, 120, 140, 180, 200, 240, 300, 360.

Idade Recomendada: 2, 4, 6, 8, 10, 11, 12, 14, 16, +18.

Estrutura de Fases e Ações
Hierarquia: Cada item de estrutura deve ser classificado como Fase, Ação ou Rodada.

Condições Especiais: São sub-itens vinculados a uma Fase/Ação específica. Cada uma adiciona 0,1 ao peso total, respeitando o teto da categoria.

5. Glossário Visual
RN05 - Composição do Glossário: Cada termo deve conter:

Palavra: O termo técnico ou nome do componente.

Definição: Texto explicativo.

Imagem: Upload opcional para auxílio visual.
