Como Funciona a Edição de Itens
Sistema de Edição Inteligente

O BGCreator permite editar todos os itens (mecânicas, componentes e temas), incluindo os pré-definidos do sistema.

Itens Criados por Você
  • Podem ser editados diretamente
  • Podem ser excluídos
  • Alterações são salvas no item original
Itens Pré-definidos do Sistema
  • Podem ser editados criando uma nova versão
  • Não podem ser excluídos
  • Nova versão fica marcada como "Editada"

Perguntas Frequentes

Uma nova versão editável é criada com suas modificações, mantendo o item original intacto. A nova versão aparece com o badge "Editado".

Não, itens pré-definidos do sistema não podem ser excluídos para manter a integridade da base de dados. Apenas itens criados por você podem ser excluídos.

Itens editados aparecem com um badge azul "Editado" ao lado do nome nas listagens. Isso indica que é uma versão personalizada de um item pré-definido.
