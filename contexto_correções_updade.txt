## 📋 REGRAS DE NEGÓCIO

### Cálculo de Peso
- Tempo: +0,1 a cada 30min (máx: 1,0)
- Mecânicas: +0,1 por item (máx: 1,0)
- Componentes: +0,1 por item (máx: 1,0)
- Condições vitória: +0,1 por item (máx: 0,3)
- Condições derrota: +0,1 por item (máx: 0,3)
- Estruturas: +0,1 por item (máx: 1,0)
- Condições especiais: +0,1 por item (máx: 1,0)

### Sistema de Versões
- **Formato**: 1.X.X (sempre inicia com 1)
- **Minor**: Incrementa com adição de conteúdo
- **Patch**: Incrementa com edições
- **Major**: Incrementa com cópias
- **Controle manual**: 6 botões para ajuste

### Controle de Acesso
- **ADMINISTRADOR**: Acesso total
- **AUTOR**: Criar/editar jogos, gerenciar conteúdo, sem exclusões
- **REVISOR**: Editar jogos, sem gerenciamento, sem exclusões
- **LEITOR**: Apenas visualizar e imprimir

## 🚀 COMO EXECUTAR

### Produção (Docker)
```bash
git clone https://github.com/seu-usuario/bgcreator.git
cd bgcreator
docker-compose up --build
```

### Desenvolvimento
```bash
# Backend
cd backend && pip install -r requirements.txt && python app/main.py

# Frontend
cd frontend && pip install -r requirements.txt && python manage.py runserver
```
